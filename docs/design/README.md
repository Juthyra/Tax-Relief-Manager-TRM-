# Design

Where the look and the screens of TRM are kept, so every developer can follow them. Start with [DES-000](DES_000_Design_System.md), the design system.

| Path | What it is |
| --- | --- |
| `DES_000_Design_System.md` | The design system: rules, colours, components |
| `components.css`, `tokens/tokens.css` | The shared styles. `tokens/theme_b_backup.css` is the unused backup direction |
| `directions/` | The two directions compared on one screen |
| `phase-<n>_<release>/<feature>/` | One folder per phase and feature, with its DES document, `mockups/` (HTML pages in `en` and `ms`) and `screenshots/` (`mobile` and `desktop`) |
| `tools/` | Scripts that build the mockup pages |

Open any page in `mockups/` in a browser to see it. The pages use test data only.
